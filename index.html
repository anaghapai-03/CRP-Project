RSA vs AES — when to use which
RSA-2048 (signatures)
  • 2 keys: private + public
  • Private key signs, public verifies
  • Proves who sent it
  • Slow — used only on small hashes
  • Can't hide content, only authenticate
AES-256-GCM (encryption)
  • 1 shared secret key
  • Same key encrypts AND decrypts
  • Hides content from others
  • Fast — encrypts any amount of data
  • GCM auth tag detects any tampering

How It Works

Mathematical step-by-step with real numbers and live demos

Part 1 — RSA Key Generation

Real RSA-2048 uses 1024-bit primes. We demonstrate the exact same math using small primes so you can verify every step by hand.

1
Choose two primes p and q
Must be prime (only divisible by 1 and themselves).
p = 61   q = 53
2
Compute n = p × q (the modulus)
This is the public modulus. Nobody can find p and q back from n — integer factorisation is hard.
n = 61 × 53 = 3233
3
Compute φ(n) = (p−1)(q−1)
φ(n) = 60 × 52 = 3120
4
Choose public exponent e
e = 17   (real RSA uses 65537)
gcd(17, 3120) = 1 ✓
5
Compute private exponent d = e⁻¹ mod φ(n)
d = 2753
Verify: (2753 × 17) mod 3120 = 1 ✓
6
Sign: C = M^d mod n
C = 65^2753 mod 3233 = 2790
7
Verify: M = C^e mod n
M = 2790^17 mod 3233 = 65 ✓
