RSA vs AES — what's the difference?
RSA (signatures above)
• Two different keys
• Private signs / Public verifies
• Proves who sent it
• Slower for large data
AES-256-GCM (this page)
• One shared secret key
• Same key encrypts AND decrypts
• Hides content from others
• Fast for any size data

Cryptography 101

Learn how cryptography works

Step 1 — RSA Key Generation
1
Pick two large random prime numbers
These are the secret foundation of your key pair. Their product creates the encryption strength.
n = p × q  ·  e.g. n ≈ 2^2048 (617 digits)
2
Compute Euler's totient
A mathematical number derived from the primes, kept secret.
3
Create your public key
This is what you share with the world so others can verify your signatures.
4
Create your private key
This is your secret. Keep it safe — only you can sign with it.
Step 2 — Signing
1
Hash your document
Creates a unique fingerprint. Even one character change gives a completely different hash.
2
Add randomness to the hash
This makes each signature unique, even for the same document signed twice.
3
Encrypt with your private key
This creates the signature. Only your private key can do this — it's your proof.
Step 3 — Verification
1
Decrypt the signature with the public key
Anyone with the public key can do this. It reveals the hash.
2
Hash the document independently
Verifier computes SHA-256 of the document they received.
3
If hash' == hash → VALID. Otherwise → TAMPERED.
Any change to the document changes its hash, breaking the equality. Mathematically unforgeable.
